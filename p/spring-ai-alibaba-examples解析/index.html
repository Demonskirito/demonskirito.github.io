用户界面（User Interface）：这是与用户交互的界面，用户通过它发出请求并接收响应。

Spring AI：这部分包含了 AI 的核心功能模块：

  • System Prompt：定义了系统的提示，用于引导 AI 模型进行对话。
  • ConversationMemory：管理对话历史，帮助 AI 保持上下文并处理长对话。
  • RAG（Retrieval-Augmented Generation）：一种增强生成式对话的技术，它结合了检索和生成模型，提高回答准确性。
  • Function Calling：调用具体功能的能力，可以与外部服务进行交互。

Vector Store API：用于存储向量数据，AI 模型可以通过它来检索和存储向量化的数据（如文档或对话内容）。

生成式 AI（Generative AI）：指的是该系统使用的 AI 模型，用于生成回答和执行任务。

服务 APIs：这些是外部服务接口，可以让 AI 系统与其他服务进行交互，例如：

  • Flight Booking Service：提供航班预订相关的 API，如查询、修改和取消预订的接口。
  • Terms of Service：用于处理服务条款的相关操作。

Booking DB：存储航班预订相关的数据，AI 可以通过它获取用户的预订详情。

文档处理（Doc Ingestion）：

  • Document Writer：负责将文档写入系统。
  • Document Transformer：处理文档转换的功能，可能包括文本格式化或转换为向量表示。
  • Document Reader：读取文档，可能用于向 AI 模型提供上下文信息。

stream()

stream() 方法表示请求流式响应。这个方法启动了一个异步流式聊天，会逐步输出模型的响应，而不是等待完整的响应返回。 使用流式响应的好处是可以实时接收和处理模型的输出。例如，聊天机器人在生成长回复时可以逐步返回内容，而不是等待整个内容生成完成后再一起返回。

content()

content() 方法从流中提取内容。这意味着它会从模型的响应流中提取聊天内容，并将其作为 Flux<String> 返回。每次聊天模型生成文本时，都会通过 Flux<String> 流式传输响应内容。 Flux<String> 是一个 Reactor 类型，表示多个字符串的异步流。这允许调用者实时处理每次收到的聊天内容。

  • 方法add(String conversationId, Message message)

  • 方法add(String conversationId, List<Message> messages)
    这是一个抽象方法，用于将一组消息（列表）添加到指定的对话ID对应的聊天历史中。实现类需要提供具体的实现。

  • 方法get(String conversationId, int lastN)
    这个方法用于获取指定对话ID的最后 lastN 条消息。返回值是一个 List<Message>，它包含了对话ID对应的最近的聊天记录。实现类需要提供如何获取和返回这些记录的具体逻辑。

  • 方法clear(String conversationId)
    这个方法用于清除指定对话ID的所有聊天记录。它没有返回值，直接清空该对话的历史记录。

@Entity
public class ChatMessage {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    private String conversationId;
    private String sender;
    private String content;
    private LocalDateTime timestamp;

    public ChatMessage() {
        this.timestamp = LocalDateTime.now();
    }

    // Getters and Setters
    public Long getId() {
        return id;
    }

    public void setId(Long id) {
        this.id = id;
    }

    public String getConversationId() {
        return conversationId;
    }

    public void setConversationId(String conversationId) {
        this.conversationId = conversationId;
    }

    public String getSender() {
        return sender;
    }

    public void setSender(String sender) {
        this.sender = sender;
    }

    public String getContent() {
        return content;
    }

    public void setContent(String content) {
        this.content = content;
    }

    public LocalDateTime getTimestamp() {

import org.springframework.beans.factory.annotation.Autowired;
import org.springframework.ai.chat.messages.Message;
import org.springframework.ai.chat.memory.ChatMemory;
import org.springframework.stereotype.Service;

import java.util.List;
import java.util.stream.Collectors;

@Service
public class ChatMemoryService implements ChatMemory {

    @Autowired
    private ChatMessageRepository chatMessageRepository;

    @Override
    public void add(String conversationId, List<Message> messages) {
        List<ChatMessage> chatMessages = messages.stream().map(msg -> {
            ChatMessage chatMessage = new ChatMessage();
            chatMessage.setConversationId(conversationId);
            chatMessage.setSender(msg.getSender());
            chatMessage.setContent(msg.getContent());
            return chatMessage;
        }).collect(Collectors.toList());
        
        chatMessageRepository.saveAll(chatMessages);
    }

    @Override
    public List<Message> get(String conversationId, int lastN) {
        List<ChatMessage> chatMessages = chatMessageRepository.findTopNByConversationIdOrderByTimestampDesc(conversationId, lastN);
        return chatMessages.stream().map(msg -> {
            Message message = new Message();
            message.setSender(msg.getSender());
            message.setContent(msg.getContent());
            return message;
        }).collect(Collectors.toList());
    }

    @Override
    public void clear(String conversationId) {
        chatMessageRepository.deleteByConversationId(conversationId);
    }
}

import java.util.List;

@RestController
@RequestMapping("/chat")
public class ChatController {

    @Autowired
    private ChatMemoryService chatMemoryService;

    // 保存聊天记录
    @PostMapping("/save")
    public String saveChat(@RequestParam String conversationId, @RequestBody List<Message> messages) {
        chatMemoryService.add(conversationId, messages);
        return "Messages saved successfully!";
    }

    // 获取聊天记录
    @GetMapping("/history")
    public List<Message> getChatHistory(@RequestParam String conversationId, @RequestParam int lastN) {

    @DeleteMapping("/clear")

        chatMemoryService.clear(conversationId);
        return "Chat history cleared!";
    }
}
